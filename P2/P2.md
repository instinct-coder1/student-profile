# P2 — Portfolio repository with an initial commit

## Aim
Create a Git repository for a portfolio and make its first commit.

## Commands
```bash
mkdir P2-portfolio
cd P2-portfolio
git init
echo "# My Portfolio" > README.md
git status
git add README.md
git commit -m "Initial portfolio commit"
```

## Explanation
- `git init` starts version control in the folder.
- `git status` shows changed and staged files.
- `git add` stages files for a commit.
- `git commit` saves a snapshot in Git history.

## Result
A local Git repository is created with its first commit. To connect a new GitHub repository, add its URL as `origin` and push the main branch.
