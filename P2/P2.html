Practical 2

Portfolio repository with an initial commit

Aim

To create a Git repository for a portfolio project and make its first commit.

Commands

mkdir my-portfolio
cd my-portfolio
git init
echo "# My Portfolio" > README.md
git status
git add README.md
git commit -m "Initial commit"

Explanation

  • git init starts Git in the project folder.
  • git status shows the current file status.
  • git add selects files for saving.
  • git commit saves the selected changes.

Connect to GitHub

git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main

Replace the sample URL with the URL of the GitHub repository you created.

Result

A local portfolio repository is created and its first commit is saved. The final commands show how to upload it to GitHub.
