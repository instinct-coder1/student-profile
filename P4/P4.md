# P4 — GitHub README and version tags

## Aim
Document a repository and create a version tag.

## Example README sections
- Project title and purpose
- Features
- Technologies used
- How to run the project
- Screenshots and author details

## Commands
```bash
git tag -a v1.0 -m "First version"
git push origin v1.0
git tag
```

## Explanation
A README explains the repository to visitors. A tag marks a particular commit with a version name such as `v1.0`.

## Result
The README structure and commands for creating and publishing a version tag are documented.
