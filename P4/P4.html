Practical 4

GitHub README and version tags

Aim

To write a README file for a GitHub project and create a version tag.

Example README.md

# My Portfolio

## About
This is my student portfolio project.

## Technologies
- HTML
- CSS
- JavaScript

## How to run
Open index.html in a web browser.

## Author
Muhammad Razin Shaikh

Git commands for version tags

git add README.md
git commit -m "Add project README"
git tag -a v1.0 -m "First version"
git push origin main
git push origin v1.0
git tag

Explanation

A README file explains the project, technologies and steps to run it. A Git tag gives a name to a particular version of the project.

Result

I learned the basic structure of a README file and the commands used to create and upload a version tag.
