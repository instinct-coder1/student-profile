Practical 1

Project folder and terminal navigation

Aim

To create a project folder and learn basic Terminal commands.

Commands

mkdir P1-terminal
cd P1-terminal
pwd
ls
mkdir practice
cd practice
cd ..

Explanation

  • mkdir creates a new folder.
  • cd changes the current folder.
  • pwd shows the current folder location.
  • ls displays files and folders.

Result

I created a project folder and practised moving between folders using Terminal.

Open Terminal and type each command one by one to perform this practical.
