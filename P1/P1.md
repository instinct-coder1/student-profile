# P1 — Project folder and terminal navigation

## Aim
Create a project folder and practise moving around it using Terminal.

## Commands
```bash
mkdir P1-terminal
cd P1-terminal
pwd
ls
mkdir notes
cd notes
cd ..
```

## Explanation
- `mkdir` creates a folder.
- `cd` enters or leaves a folder.
- `pwd` prints the current folder path.
- `ls` lists the files and folders.

## Result
The P1 project folder and its notes folder are created. The commands demonstrate basic terminal navigation.
