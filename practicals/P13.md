# P13: Choosing between Flexbox and Grid for a shared layout

Aim: Compare Flexbox and CSS Grid and use each where suitable.

| Flexbox | CSS Grid |
|---|---|
| Best for one-dimensional rows or columns | Best for two-dimensional rows and columns |
| Useful for navbars and footers | Useful for card grids and page sections |

In this portfolio, Flexbox is used for the header, navigation, hero, interest cards and footer. Grid is used for project cards and practical links.

Result: Both layout systems are used for the parts they handle best.
