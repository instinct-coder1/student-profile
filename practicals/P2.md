# P2: Portfolio repo with an initial commit

Aim: Track the portfolio project with Git and upload it to GitHub.

```bash
git init
git status
git add .
git commit -m "Initial portfolio commit"
git branch -M main
git remote add origin https://github.com/instinct-coder1/student-profile.git
git push -u origin main
```

Git tracks file changes. `git add` stages files, `git commit` saves a version, and `git push` uploads commits.

Result: The portfolio is maintained in the `student-profile` GitHub repository.
