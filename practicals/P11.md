# P11: Newspaper-style three-column layout with CSS Grid

Aim: Understand a three-column layout using CSS Grid.

Example:
```css
.newspaper {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 1rem;
}
```

This creates three equal columns. A media query can reduce the number of columns on smaller screens.

Result: The CSS Grid three-column technique was demonstrated. The portfolio also uses Grid for its project and practical cards.
