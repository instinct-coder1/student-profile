# P8: Sticky navbar and card overlay using CSS positioning

Aim: Use CSS positioning for a sticky navbar and a card overlay.

The header uses `position: sticky`, `top: 0` and `z-index`. The profile card uses `position: relative`; its `::before` pseudo-element creates a decorative outline behind it.

Result: The navbar remains at the top during scrolling and the profile card has a layered outline.
