# P7: Design tokens and typography system in CSS

Aim: Create reusable CSS values for colours, spacing and typography.

The `:root` selector in `style.css` defines custom properties such as `--bg`, `--surface`, `--accent`, `--font` and `--radius`.

CSS variables keep the design consistent. A shared value can be changed once and reused across the page.

Result: A small reusable CSS design system was created.
