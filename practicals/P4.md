# P4: GitHub README and version tags

Aim: Document a project and mark a version.

```bash
git tag -a v1.0 -m "First portfolio version"
git push origin v1.0
git tag
```

A README explains the project and how to run it. A Git tag gives a name to a specific commit, for example `v1.0`.

Result: The repository README documents the project. The commands demonstrate how to publish a version tag.
