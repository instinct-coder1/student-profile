# P1: Project folder and terminal navigation

Aim: Create a project folder and practise terminal navigation.

Commands:
```bash
mkdir student-profile
cd student-profile
pwd
ls
mkdir practicals
cd ..
```

`mkdir` creates a folder, `cd` changes folders, `pwd` displays the current path, and `ls` lists files.

Result: The project folder and its practicals folder were created, and basic navigation commands were practised.
