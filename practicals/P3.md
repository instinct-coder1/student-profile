# P3: Feature-branch Git workflow

Aim: Work on a feature in a separate branch.

```bash
git switch -c feature/about-section
# Make and save a change
git add .
git commit -m "Add about section"
git push -u origin feature/about-section
git switch main
```

A branch keeps new work separate from the stable main branch. After checking it, the feature can be merged through a GitHub pull request.

Result: The feature-branch workflow was practised.
