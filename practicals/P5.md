# P5: Semantic bio page

Aim: Create a biography page using semantic HTML.

The About section in `index.html` uses `<section>` for grouped content and `<article>` for the biography. The page also uses `<header>`, `<main>` and `<footer>`.

Semantic elements describe the meaning of content and make the page structure easier to understand.

Result: A student biography section was created using meaningful HTML elements.
