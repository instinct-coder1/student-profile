Practical 3

Feature-branch Git workflow

Aim

To create a feature branch and save changes separately from the main branch.

Commands

git switch -c feature/about-page
# Make a change in a project file
git status
git add .
git commit -m "Add about page"
git push -u origin feature/about-page
git switch main

Explanation

  • A branch is a separate line of development.
  • git switch -c creates and opens a new branch.
  • git add stages the changed files.
  • git commit saves the changes.
  • git push uploads the branch to GitHub.

Merge the feature

After checking the work, create a pull request on GitHub. Review it and merge it into the main branch.

Result

I learned how to work on a feature branch without directly changing the main branch.
