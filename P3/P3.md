# P3 — Feature-branch Git workflow

## Aim
Create and use a separate branch for a feature.

## Commands
```bash
git switch -c feature/about-section
# Make a change to a project file
git status
git add .
git commit -m "Add about section"
git push -u origin feature/about-section
git switch main
```

## Explanation
A branch lets us work on a feature without directly changing the main branch. The feature can later be reviewed and merged with a pull request.

## Result
The commands show how to create a feature branch, commit a change and push the branch to GitHub.
